# Personal Projects

Creative coding experiments and personal projects by Ian Zimmerman.

## Christmas Animation

A p5.js animation that moves from Christmas Eve through Christmas morning, featuring a snowy neighborhood, Santa and Rudolph, presents, and falling snow.

**Concepts:** Animation, state transitions, reusable drawing functions, and keyboard and mouse interaction.

**Code:** [christmas-animation/sketch.js](christmas-animation/sketch.js)

**Controls:** Click the canvas to enable browser audio (the audio file `hohoho.mp3` is not included). Press R to restart the animation.

**Requirements:** Runs in p5.js.

## Four Seasons Tree Animation

A music-reactive p5.js animation of a Vermont-inspired maple tree progressing through the four seasons, paired with Vivaldi's *The Four Seasons*.

**Concepts:** L-systems, procedural branching, seasonal state transitions, audio-reactive weather, and snow accumulation based on branch angle and thickness.

**Project:** [Overview and report](four-seasons-tree/README.md)

**Code:** [four-seasons-tree/sketch.js](four-seasons-tree/sketch.js)

**Controls:** Click the canvas to start the animation and music (the audio file `four-seasons.mp3` is not included). Press R to restart the animation.

**Requirements:** Runs in p5.js. Add `audio/four-seasons.mp3` or `four-seasons.mp3`; audio playback time controls the seasonal transitions.

**Live sketch:** [Open the original p5.js sketch](https://editor.p5js.org/Ian_Zimmerman/sketches/ZiT6xI-U_)
