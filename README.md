# Personal Projects

Creative coding experiments and personal projects by Ian Zimmerman.

## Christmas Animation

A p5.js animation that moves from Christmas Eve through Christmas morning, featuring a snowy neighborhood, Santa and Rudolph, presents, and falling snow.

**Concepts:** Animation, state transitions, reusable drawing functions, and keyboard and mouse interaction.

**Code:** [christmas-animation/sketch.js](christmas-animation/sketch.js)

**Controls:** Click the canvas to enable browser audio (audio file `hohoho.mp3` is not included). Press R to restart the animation.

**Requirements:** Runs in p5.js.
