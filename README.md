## Christmas Animation

A p5.js animation that moves from Christmas Eve through Christmas morning, featuring a snowy neighborhood, Santa and Rudolph, presents, and falling snow.

**Concepts:** Animation, state transitions, reusable drawing functions, and keyboard and mouse interaction.

**Code:** [christmas-animation/sketch.js](christmas-animation/sketch.js)

**Controls:** Click the canvas to enable browser audio. Press R to restart the animation.

**Requirements:** A compatible p5.js environment with p5.sound and an audio file named `hohoho.mp3` in the sketch directory. The audio file is not included. The supplied sketch is preserved as written; this repository does not yet include a standalone webpage or verified live demo.
