# Four Seasons Tree Animation

By Ian Zimmerman

A p5.js animation that tells the story of a maple tree through spring, summer, autumn, and winter, accompanied by Vivaldi's *The Four Seasons*. The tree was inspired by the maple trees Ian grew up with in Vermont and photographs of fall foliage sent by his mother.

## How it works

- An adapted L-system generates the maple-like branching structure.
- Music timestamps determine the season and when leaves grow, change color, and fall.
- Audio volume determines weather intensity, creating a scene that reacts to the music.
- Branch angle, measured using `sin()`, and branch thickness determine how much snow each branch can hold.
